# CNNA 2-form closure / 3-form defect gate

Run:

```bash
python3 test_2form_closure_and_3form_defect_gate.py
```

Default output:

```text
2form_closure_3form_defect_out_L2/
cnna_2form_closure_3form_defect_gate_pkg_L2.zip
```

Recommended quick rerun:

```bash
python3 test_2form_closure_and_3form_defect_gate.py   --max-level 2   --out 2form_closure_3form_defect_out_L2   --zip cnna_2form_closure_3form_defect_gate_pkg_L2.zip
```
