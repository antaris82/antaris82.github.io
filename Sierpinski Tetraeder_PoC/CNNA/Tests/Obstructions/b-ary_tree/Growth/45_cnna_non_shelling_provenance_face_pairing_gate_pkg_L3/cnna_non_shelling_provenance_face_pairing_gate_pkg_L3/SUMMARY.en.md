# SUMMARY

Test package: `test_cqnm_non_shelling_provenance_face_pairing_gate.py`

## What was tested

The test verifies the permitted growth moves rather than simply rerunning larger levels. It begins with the current inward-root/outward-NGF complex generated by Script-1/2-style provenance growth and then enumerates possible closure moves:

- `shelling_disk_move`: one tetrahedron attached to one boundary face.
- `cap_move`: local multi-face cap/filling move.
- `handle_candidate`: non-shelling bridge between two separated boundary faces using a triangular-prism-like 3-tet bridge.
- `quotient_candidate`: orientation-reversing identification of two separated boundary faces.
- `illegal`: rejected by occupancy/dependency/quotient degeneracy checks.

## Short conclusion

The current base growth is still ball-like: beta1=beta2=0. However, the boundary already contains many non-shelling candidates. In the real-growth run, the best quotient candidate has a response rank of 1, and the best handle candidate has a response rank of 3. The best handle candidate would produce delta_beta2=1 in this audit model.

This means the current failure is not that no local K exists, nor that no non-shelling boundary opportunities exist. The failure is that the growth law never applies a complementary boundary-pairing/handle move.

## Important control warning

The symmetrized and no-backreaction controls also produce top-ranked non-shelling candidates. Therefore, this package does not prove that the non-shelling move is already CNNA-derived from response/backreaction. It proves a more precise negative/diagnostic statement: the current growth operation is too weak. A separate rule is needed to determine when a candidate non-shelling move is genuinely forced by provenance rather than merely available combinatorially.
